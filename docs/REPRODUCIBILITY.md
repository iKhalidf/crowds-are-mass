# Reproducibility and provenance

## What can be reproduced immediately

`python scripts/reproduce_tables.py` reconstructs pooled and stratified scores
from the bundled numeric artifacts, including all five forecasters for GCS and
indoor. It requires only NumPy, checks complete clip matching, and writes Markdown,
CSV, and JSON. The strata are dataset-specific quartiles of the true future
headcount range. Matching uses rounded ground-truth count signatures; duplicate
or missing signatures cause an error instead of silently dropping clips.

This verifies aggregation of the stored metrics. It does **not** recompute the
per-frame transport or JS from full density maps. `gt`, `pred`, and `obs` in
these artifacts are count series, not 80×80 density maps. Selected full-map
archives, raw annotations, and weights remain outside version control.

## Recorded Stream-CDF runs

| Setting | GCS | Indoor |
|---|---:|---:|
| Observed / forecast frames | 8 / 12 | 8 / 12 |
| Training epochs | 20 | 40 |
| Width / encoder depth / heads | 256 / 4 / 4 | 256 / 4 / 4 |
| Encoder / decoder tubelet | 4 / 2 | 4 / 2 |
| Temporal embeddings | absolute | absolute |
| Training epsilon / iterations / pooling | 2.0 / 30 / 2 | 2.0 / 30 / 2 |
| Training objective | debiased | debiased |
| Output activation / gain / bound | softplus / 10 / 50 | softplus / 10 / 50 |
| Dropout / seed | 0 / 0 | 0 / 0 |
| Batch / learning rate / gradient clip | 8 / 0.00025 / 750 | 8 / 0.00025 / 750 |

Evaluation uses kappa 8, epsilon 0.25, 60 iterations, no pooling, and float64.
It reports **raw** transport plus kappa times unmatched mass. The self terms
subtracted during training are not subtracted from the reported evaluation cost.
ALiBi is an optional implementation path; the reported runs did not use it or
an incremental KV cache. Final-epoch Stream-CDF checkpoints were used; CrowdMAC
used its separately selected checkpoint from the supplied reproduction recipe.

`configs/` records settings and artifact checksums, not a claim that the original
software environment was captured. Requirements are dependency declarations,
not a recovered historical lockfile. No exact original CUDA/package lock was
supplied. New runs may differ; the paper reports one run per forecaster.

## Source preparation

The canonical model comes from `stream_cdf_v4.py`; its solver and model code are
retained in `streamcdf/model.py`. `stream_cdf_fixes.py` becomes
`streamcdf/transport.py`, and `train_v5.py` becomes `scripts/train.py`.
`docs/source_manifest.json` records original hashes. The original backup folders
remain untouched locally and are excluded from Git.

Repository adaptations replace fixed cluster paths with repository/data paths,
make imports explicit, set training defaults to the recorded GCS settings, and
default data-loader workers to zero for portable execution. NumPy reports never
import training dependencies. The original paper source is preserved byte for
byte during repository preparation.

The reference JS computation forms a mixture from unnormalized maps before
normalizing its KL arguments. Proportional maps receive the perfect score, but
for differing shapes the result can depend on count ratios and need not obey
the standard JS bound of log(2). Unmatched mass is also not pure count error.

## Limits

The missing original GCS data/split, remaining manuscript figure/style assets, and omitted
weights prevent a complete end-to-end paper rebuild from this snapshot alone.
The kappa sweep and qualitative figures are not regenerated by the table command.
No synthetic replacement results are substituted for those experiments.
